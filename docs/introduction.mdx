# Welcome to VectorSync

VectorSync is a Go-based API service for vector storage and retrieval. It wraps PostgreSQL with pgvector, exposing vector similarity search, full-text search, and hybrid search through both gRPC and HTTP/JSON endpoints.

## Key Features

<CardGroup cols={2}>
  <Card title="Vector Similarity Search" icon="magnifying-glass">
    Cosine, Euclidean, and Inner Product distance with configurable top-K
  </Card>
  <Card title="Full-Text Search" icon="font">
    Keyword search on document content with relevance ranking
  </Card>
  <Card title="Dual API Support" icon="code">
    Native gRPC with HTTP/JSON gateway via grpc-gateway
  </Card>
  <Card title="Collection Management" icon="folder">
    Organize embeddings into collections with fixed dimensions
  </Card>
  <Card title="CRUD + Upsert" icon="database">
    Insert, upsert, retrieve, and delete documents with embeddings
  </Card>
  <Card title="Hybrid Search" icon="arrows-rotate">
    Weighted combination of vector similarity and full-text search
  </Card>
  <Card title="Batch Operations" icon="layer-group">
    Insert and delete up to 1000 documents per request
  </Card>
  <Card title="HNSW Indexing" icon="bolt">
    Automatic per-collection HNSW index for fast approximate nearest neighbor search
  </Card>
</CardGroup>

## Architecture Overview

VectorSync uses a layered architecture with in-memory collection caching and PostgreSQL as the persistent storage:

```
┌─────────────────────────────────────────────────────┐
│                   Client Apps                       │
└────────────┬────────────────────┬───────────────────┘
             │                    │
        gRPC │               HTTP │ (grpc-gateway)
             │                    │
┌────────────┴────────────────────┴───────────────────┐
│              VectorSync Server                      │
│                      │                              │
│                      │ Atomic Writes                │
│                      ▼                              │
│  ┌──────────────────────────────────────────────┐   │
│  │   PostgreSQL + pgvector Extension            │   │
│  │   - Collections table                        │   │
│  │   - Documents table (vectors + metadata)     │   │
│  └──────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```
