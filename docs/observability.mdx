---
title: Observability
description: Prometheus metrics exposed by VectorSync
---

VectorSync exposes Prometheus metrics on the HTTP gateway port at `/metrics`.
No separate listener — same port as the REST API (`:8080` by default).

```bash
curl http://localhost:8080/metrics
```

## Metric reference

All metrics are namespaced under `vectorsync_`.

### gRPC

| Metric | Type | Labels | Description |
|---|---|---|---|
| `vectorsync_grpc_request_duration_seconds` | Histogram | `method`, `code` | Unary RPC latency. |
| `vectorsync_grpc_requests_inflight` | Gauge | `method` | Currently-executing unary RPCs. |

### HTTP gateway

| Metric | Type | Labels | Description |
|---|---|---|---|
| `vectorsync_http_request_duration_seconds` | Histogram | `code` | Gateway request latency. |

Path is intentionally not labelled — per-method latency is already captured by the gRPC histogram, and an unbounded path label would explode cardinality on collection-id paths.

### Database pool (scraped from `sql.DB.Stats()`)

| Metric | Type | Description |
|---|---|---|
| `vectorsync_db_open_connections` | Gauge | Open connections (in use + idle). |
| `vectorsync_db_in_use_connections` | Gauge | Connections currently in use. |
| `vectorsync_db_idle_connections` | Gauge | Idle connections. |
| `vectorsync_db_wait_total` | Counter | Pool wait events. |
| `vectorsync_db_wait_duration_seconds_total` | Counter | Cumulative wait time. |
| `vectorsync_db_max_idle_closed_total` | Counter | Connections closed due to `MaxIdleConns`. |
| `vectorsync_db_max_lifetime_closed_total` | Counter | Connections closed due to `ConnMaxLifetime`. |

### Collection cache

| Metric | Type | Labels | Description |
|---|---|---|---|
| `vectorsync_cache_ops_total` | Counter | `result` (`hit`/`miss`) | Collection-cache lookups. |

### HNSW

| Metric | Type | Description |
|---|---|---|
| `vectorsync_hnsw_build_duration_seconds` | Histogram | Async HNSW index build wall time. |
| `vectorsync_hnsw_build_errors_total` | Counter | Failed background HNSW builds. |

### Ingestion pipeline

| Metric | Type | Labels | Description |
|---|---|---|---|
| `vectorsync_ingest_chunks_total` | Counter | `strategy` | Chunks produced. |
| `vectorsync_ingest_embed_calls_total` | Counter | `provider`, `status` | Embedding-provider invocations. |
| `vectorsync_ingest_embed_duration_seconds` | Histogram | `provider` | Embedding-provider latency. |

## Example PromQL

p99 search latency per RPC:

```promql
histogram_quantile(0.99,
  sum by (method, le) (
    rate(vectorsync_grpc_request_duration_seconds_bucket[5m])
  )
)
```

Cache hit ratio:

```promql
sum(rate(vectorsync_cache_ops_total{result="hit"}[5m]))
  /
sum(rate(vectorsync_cache_ops_total[5m]))
```

Pool saturation:

```promql
vectorsync_db_in_use_connections / vectorsync_db_open_connections
```

Error rate by RPC:

```promql
sum by (method) (rate(vectorsync_grpc_request_duration_seconds_count{code!="OK"}[5m]))
```

## Prometheus scrape config

```yaml
scrape_configs:
  - job_name: vectorsync
    scrape_interval: 15s
    static_configs:
      - targets: ['vectorsync:8080']
```
