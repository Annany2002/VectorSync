## Create Document

Insert a new document with a vector embedding into a collection.

<Tabs>
  <Tab title="HTTP">
    ```bash
    curl -X POST http://localhost:8080/api/v1/documents \
      -H "Content-Type: application/json" \
      -d '{
        "collection_id": "COLLECTION_ID",
        "vector": [0.1, 0.2, 0.3],
        "content": "Document content",
        "metadata": {
          "category": {"value": "example"}
        }
      }'
    ```
  </Tab>
  <Tab title="gRPC">
    ```bash
    grpcurl -plaintext -d '{
      "collection_id": "COLLECTION_ID",
      "vector": [0.1, 0.2, 0.3],
      "content": "Document content"
    }' localhost:6309 document.DocumentService/CreateDocument
    ```
  </Tab>
</Tabs>

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `collection_id` | string (UUID) | Yes | Target collection ID |
| `vector` | array[float] | Yes | Vector embedding (must match collection dimension) |
| `content` | string | No | Text content of the document |
| `metadata` | object | No | Key-value metadata for filtering |

### Response

```json
{
  "document": {
    "id": "770e8400-e29b-41d4-a716-446655440002",
    "createdAt": "2026-01-15T11:00:00Z",
    "updatedAt": "2026-01-15T11:00:00Z",
    "collectionId": "COLLECTION_ID",
    "content": "Document content",
    "vector": [0.1, 0.2, 0.3],
    "metadata": {"category": {"value": "example"}}
  }
}
```

## Upsert Document

Insert a new document or update an existing one by ID.

<Tabs>
  <Tab title="HTTP">
    ```bash
    curl -X PUT http://localhost:8080/api/v1/documents/{id} \
      -H "Content-Type: application/json" \
      -d '{
        "collection_id": "COLLECTION_ID",
        "vector": [0.4, 0.5, 0.6],
        "content": "Updated content"
      }'
    ```
  </Tab>
  <Tab title="gRPC">
    ```bash
    grpcurl -plaintext -d '{
      "id": "DOCUMENT_UUID",
      "collection_id": "COLLECTION_ID",
      "vector": [0.4, 0.5, 0.6],
      "content": "Updated content"
    }' localhost:6309 document.DocumentService/UpsertDocument
    ```
  </Tab>
</Tabs>

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string (UUID) | Yes | Document ID (used as conflict key) |
| `collection_id` | string (UUID) | Yes | Target collection ID |
| `vector` | array[float] | Yes | Vector embedding |
| `content` | string | No | Text content |
| `metadata` | object | No | Key-value metadata |

### Response

```json
{
  "document": {
    "id": "DOCUMENT_UUID",
    "createdAt": "2026-01-15T11:00:00Z",
    "updatedAt": "2026-01-15T11:30:00Z",
    "collectionId": "COLLECTION_ID",
    "content": "Updated content",
    "vector": [0.4, 0.5, 0.6]
  },
  "isNew": false
}
```

<Info>
The `isNew` field indicates whether the document was created (`true`) or updated (`false`).
</Info>

## List Documents

List documents in a collection with pagination.

<Tabs>
  <Tab title="HTTP">
    ```bash
    curl "http://localhost:8080/api/v1/documents?collection_id=COLLECTION_ID&limit=50&offset=0"
    ```
  </Tab>
  <Tab title="gRPC">
    ```bash
    grpcurl -plaintext -d '{
      "collection_id": "COLLECTION_ID",
      "limit": 50,
      "offset": 0
    }' localhost:6309 document.DocumentService/ListDocuments
    ```
  </Tab>
</Tabs>

### Query Parameters

| Parameter | Type | Default | Max | Description |
|-----------|------|---------|-----|-------------|
| `collection_id` | string | - | - | Required collection ID |
| `limit` | integer | 50 | 1000 | Documents per page |
| `offset` | integer | 0 | - | Pagination offset |

## Batch Insert Documents

Insert multiple documents into a collection in a single atomic operation.

<Tabs>
  <Tab title="HTTP">
    ```bash
    curl -X POST http://localhost:8080/api/v1/documents/batch \
      -H "Content-Type: application/json" \
      -d '{
        "collection_id": "COLLECTION_ID",
        "documents": [
          {
            "content": "First document",
            "vector": [0.1, 0.2, 0.3],
            "metadata": {"category": {"value": "example"}}
          },
          {
            "content": "Second document",
            "vector": [0.4, 0.5, 0.6]
          }
        ]
      }'
    ```
  </Tab>
  <Tab title="gRPC">
    ```bash
    grpcurl -plaintext -d '{
      "collection_id": "COLLECTION_ID",
      "documents": [
        {"content": "First document", "vector": [0.1, 0.2, 0.3]},
        {"content": "Second document", "vector": [0.4, 0.5, 0.6]}
      ]
    }' localhost:6309 document.DocumentService/BatchInsert
    ```
  </Tab>
</Tabs>

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `collection_id` | string (UUID) | Yes | Target collection ID |
| `documents` | array | Yes | Array of documents to insert |
| `documents[].vector` | array[float] | Yes | Vector embedding (must match collection dimension) |
| `documents[].content` | string | No | Text content of the document |
| `documents[].metadata` | object | No | Key-value metadata for filtering |

### Response

```json
{
  "insertCount": 2,
  "documents": [
    {
      "id": "f1f566da-2192-4407-953c-608e50803a58",
      "createdAt": "2026-01-26T11:14:23Z",
      "updatedAt": "2026-01-26T11:14:23Z",
      "collectionId": "COLLECTION_ID",
      "content": "First document",
      "vector": [0.1, 0.2, 0.3]
    },
    {
      "id": "0f9f56ec-1a83-4c3d-b70b-ca4e97e707a7",
      "createdAt": "2026-01-26T11:14:23Z",
      "updatedAt": "2026-01-26T11:14:23Z",
      "collectionId": "COLLECTION_ID",
      "content": "Second document",
      "vector": [0.4, 0.5, 0.6]
    }
  ]
}
```

<Warning>
This is an **atomic operation**. If any document fails validation (e.g., dimension mismatch), the entire batch is rejected and no documents are inserted.
</Warning>

## Batch Delete Documents

Delete multiple documents from a collection in a single atomic operation.

<Tabs>
  <Tab title="HTTP">
    ```bash
    curl -X POST http://localhost:8080/api/v1/documents/batch-delete \
      -H "Content-Type: application/json" \
      -d '{
        "collection_id": "COLLECTION_ID",
        "documentIds": [
          "770e8400-e29b-41d4-a716-446655440001",
          "770e8400-e29b-41d4-a716-446655440002"
        ]
      }'
    ```
  </Tab>
  <Tab title="gRPC">
    ```bash
    grpcurl -plaintext -d '{
      "collection_id": "COLLECTION_ID",
      "documentIds": [
        "770e8400-e29b-41d4-a716-446655440001",
        "770e8400-e29b-41d4-a716-446655440002"
      ]
    }' localhost:6309 document.DocumentService/BatchDelete
    ```
  </Tab>
</Tabs>

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `collection_id` | string (UUID) | Yes | Target collection ID |
| `documentIds` | array[string] | Yes | Array of document IDs to delete (max 1000) |

### Response

```json
{
  "deletedCount": 2,
  "documents": [
    {
      "id": "770e8400-e29b-41d4-a716-446655440001",
      "createdAt": "2026-01-15T11:00:00Z",
      "updatedAt": "2026-01-15T11:00:00Z",
      "collectionId": "COLLECTION_ID",
      "content": "First document",
      "vector": [0.1, 0.2, 0.3]
    },
    {
      "id": "770e8400-e29b-41d4-a716-446655440002",
      "createdAt": "2026-01-15T11:00:00Z",
      "updatedAt": "2026-01-15T11:00:00Z",
      "collectionId": "COLLECTION_ID",
      "content": "Second document",
      "vector": [0.4, 0.5, 0.6]
    }
  ]
}
```

<Warning>
This is an **atomic operation**. All specified documents must belong to the given collection. The operation deletes all documents or none.
</Warning>
